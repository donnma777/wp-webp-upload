# WebP Upload

WordPress でアップロードした JPEG / PNG を、自動で WebP に変換して軽くするプラグインです。サムネイルなどのサイズ違いも WebP で作ります。有効化するだけで動きます。

元の画像を残しておけば、あとから画質を落とさずに JPEG / PNG へ戻せます。

## ルール

- WebP にしたほうが大きくなるときは、元のままにします
- アニメーション GIF・SVG・すでに WebP のものは、そのままです
- ファイル名の最後が `-orig` なら変換しません（例: `logo-orig.png`）
- 画質は JPEG からは 82、PNG からは 90 です
- 大きい画像（2560px 超）は、WordPress 本体が縮めた版（`-scaled`）も作ります。WebP には位置情報などの EXIF は残りません

サーバーによっては、Imagick が WebP を書き出せずに黙って JPEG で保存してしまうことがあります。そのため、WebP を書き出せるエディター（GD など）を選び、本当に WebP になったときだけ変換します。WebP を書き出せないサーバーでは、何もせず元のまま置きます。

## 設定と、元に戻す・消す

管理画面の「メディア → WebP 変換」（プラグイン一覧の「設定」からも開けます）で使います。

- **WebP に変換する**（初期値はオン）：外すと変換を一時停止します。そのあいだに上げた画像は JPEG / PNG のまま置きます
- **作らないサイズ**：チェックしたサイズ違いは、これから上げる画像では作りません。WebP に変換しない画像も含めて、サイト全体に効きます。すでにあるファイルは消しません
  - 迷ったら `1536x1536` と `2048x2048` だけ止めるのがおすすめです。ブログの本文の幅ではほとんど使われません
  - テーマやプラグインのサイズを止めると、一覧のサムネイルなどで大きい画像を縮めて表示するため、かえって重くなることがあります
- **元の画像を残す**（初期値はオン）：変換前の JPEG / PNG を、`uploads/webp-upload-originals-（ランダムな文字）/` に残します。オフにすると、元の画像は消します
- **一括で元に戻す**：WebP を JPEG / PNG に戻します。サイズ違いを作り直し、記事の本文の画像 URL を書き換えて、WebP を消します
  - 元の画像が残っているものは、それをそのまま使います（画質は落ちません）
  - 残っていないものは、選べば WebP から変換し直して戻せます（画質が少し落ちます。透明な部分がある画像は PNG に、それ以外は JPEG にします）
- **1枚ずつ元に戻す**：メディアの一覧（リスト表示）の各行か、画像の詳細から戻せます
- **残した元の画像をすべて消す**：WebP のまま使い続けると決めたら、容量を空けられます

元に戻すときに書き換えるのは、記事・固定ページの本文の URL だけです。テーマの設定やカスタムフィールドなど、本文以外に書いた URL は書き換えません。アイキャッチ画像など、ID で選んでいるものはそのまま新しい画像になります。

### 元の画像の置き場所について

元の画像には、スマホで撮った写真の位置情報などがそのまま残っています。そのため、フォルダ名にランダムな文字を付けて URL を推測されにくくし、`.htaccess` で外から見られないようにしています。

`.htaccess` が効くのは Apache / LiteSpeed のサーバーです。nginx のサーバーでは、フォルダ名を推測されにくくしているだけなので、気になる場合は「元の画像を残す」をオフにしてください。

## インストール

1. [Releases](https://github.com/donnma777/wp-webp-upload/releases) から `wp-webp-upload.zip` をダウンロード
2. WordPress の管理画面「プラグイン → 新規追加 → プラグインのアップロード」で zip を選び、有効化

有効化する前にアップロードした画像は変換しません。

## 使うのをやめるとき

しばらく変換を止めたいだけなら、設定の「WebP に変換する」を外してください。

やめるときは、無効化するだけで大丈夫です。これから上げる画像は変換されなくなり、すでに WebP にした画像はそのまま使えます。（「作らないサイズ」の設定も効かなくなり、WordPress の通常どおりに戻ります）

JPEG / PNG に戻したいときは、無効化する前に「一括で元に戻す」を使ってください。

## 動作環境

- WordPress 6.0 以上
- PHP 8.0 以上
- WebP を書き出せる GD または Imagick

## 一緒に使うと便利なもの

[Folder Upload](https://github.com/donnma777/wp-folder-upload) で置いたファイルは変換しません（置いたままの形で使うため）。

## 注意

- 「元の画像を残す」をオフにしているときや、元の画像を消したあとは、元に戻すと画質が少し落ちます
- 管理画面は日本語のみです
- 個人で作ったものです。サポートや不具合対応のお約束はできません
